# Security reports

Report a suspected security problem privately to **arn-privacy@qysley.se**.
Include the affected component/version, time and a minimal synthetic
reproduction. Do not send passwords, tokens, cookies, private keys, customer
records or full authentication headers. Do not disclose an exploit in a public
issue while confidential handling is needed.

No response-time SLA or verified secure file-transfer channel is promised.
If sensitive evidence is necessary, agree a suitable delivery method first.
Do not probe production accounts, consume other users' quota or test payments
without explicit permission. This document authorizes no security testing.

The currently reviewed release candidate is 1.0.4; publication and deployment
require separate approval. This is a reporting contact, not evidence that the
release's email-delivery acceptance tests have been completed.
